# Борис 🤖

Телеграм-бот на модели GLM (Z.ai), круглосуточно живёт на GitHub Actions.

## Запуск (5 минут)

1. Создайте **публичный** репозиторий на GitHub (публичный = Actions бесплатны).
2. Скопируйте туда `bot.py` и папку `.github/workflows/`.
3. В настройках репозитория: **Settings → Secrets and variables → Actions → New repository secret** — добавьте два секрета:
   - `TELEGRAM_TOKEN` — токен бота от @BotFather
   - `ZAI_API_KEY` — ключ с https://z.ai/manage-apikey/apikey-list
4. Вкладка **Actions** → workflow `boris` → **Run workflow** (или ждите cron).
5. Напишите боту в Telegram — он ответит.

## Как это работает

- Actions запускает `bot.py` каждые 5 часов (лимит одного job — 6 ч).
- Между перезапусками пауза до 10 минут: сообщения копятся в Telegram и приходят после рестарта, ничего не теряется.
- Ключи живут в Secrets и в код не попадают.

## Синхронизация памяти с компьютеров

Скрипт `sync_memory.py` читает локальные чаты ZCode на любом компьютере, выделяет из новых диалогов факты и заливает их в `facts.json` (долговременная память Бориса). Бот подтягивает обновления из репозитория раз в ~10 минут.

Настройка на компьютере (один раз):
1. Python 3.10+ и `gh auth login` (для прав на push).
2. Ключ Z.ai в файл `~/.boris/zai_key` (или env `ZAI_API_KEY`).
3. `git clone https://github.com/gregoryger/boris-bot && cd boris-bot`
4. Проверка вручную: `python sync_memory.py` (только новое; `--full` — всё).
5. Расписание: звать скрипт раз в день (на Windows — Планировщик задач; на Linux/Mac — cron).

Примечание: репозиторий публичный — `facts.json`/`memory.json` видны всем.

## Важно

- Если бот также подключён в приложении ZCode (окно «Боты») — **выключите его там**, иначе два опрашивателя будут конфликтовать (ошибка 409).
